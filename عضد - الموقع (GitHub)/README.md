# عضد (Adud)

منصة تربط مشاريع التخرج والهاكاثونات وريادة الأعمال بأصحاب التخصصات والمهارات.

نسخة تجريبية من الواجهة: ملف واحد `index.html` (HTML + CSS + JavaScript) بدون أي مكتبات أو بناء.
البيانات تجريبية وتُحفظ في `localStorage` للمتصفح فقط.

## التشغيل
افتح `index.html` في المتصفح، أو انشره على GitHub Pages (Settings > Pages > Deploy from branch > main / root).

## الصفحات
الرئيسية، المشاريع، المواهب، الفعاليات، كيف يعمل، انشر مشروعك، ملفي.
تعمل على الجوال (شريط تنقل سفلي) واللابتوب (قائمة علوية).
